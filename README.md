# Shop Apps

Phone web apps for the shop. Open on a phone and use "Add to Home Screen".

- **CNC Check** (`cnc-check/`): checks a CNC program for crashes against a blank measured from photos and a blueprint.
- **Tool Crib** (`tool-crib/`): catalogs tools from photos, tracks how many are on hand, and warns when a tool is within 2 of its reorder point.
